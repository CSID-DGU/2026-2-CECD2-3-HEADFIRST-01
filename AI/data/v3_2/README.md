## 부탁 (조수현)

1. A, B를 **A′와 같은 조건**으로 학습: 4bit QLoRA, r 16, alpha 32, 같은 lr·max_len, 검증 파일 동일. epoch도 A′와 같은 기준으로 고르기(A′는 2번째 에폭)
2. 평가는 11/18과 같은 조건(vLLM + fp8, temperature 0)으로
   - 하드 dev 100: 예측 파일(`pred_dev_v32A.jsonl`, `pred_dev_v32B.jsonl`)
   - 하드 test 200: `score_hard.py score` / `compare --base pred_test_Aprime.jsonl --model …` **표만**
   - raw 테스트 62 · 실발화 227 · 생성 620: 점수(실제 발화에서 떨어지지 않았는지 확인용)
3. 시간이 부족하면 A 먼저
