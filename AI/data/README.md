# AI/data 안내

## 학습 데이터 버전

| 버전 | 줄 수 | 무엇을 바꿨나 | 이 데이터로 학습한 모델 |
|---|---:|---|---|
| v2 | 5,000 | 처음 만든 생성 데이터(발화 패턴 31개) | 베이스라인 평가용 |
| v3 | 5,000 | 실제 노인 발화를 참고한 패턴 4개 추가. UNCERTAIN 4.7% | A |
| v3.1 | 5,052 | UNCERTAIN(재질문 대상) 문장 302건 추가. UNCERTAIN 9.9% | A′ (메인 모델) |
| v3.2 A | 6,909 | v3.1 전부 + 오답 유형으로 바꿔 쓴 문장 1,857건. UNCERTAIN 19.9% | 실험 A |
| v3.2 B | 6,900 | 같은 문장 반복을 줄인 v3.1(4,315) + 바꿔 쓴 문장 1,857 + 말투만 바꾼 문장 728 | 실험 B |

- INFORM: 발화에서 값을 뽑을 수 있음. UNCERTAIN: 값을 확정할 수 없어 재질문이 필요함.
- 비율은 정답 action 기준이다.

## 폴더

| 폴더 | 내용 |
|---|---|
| `v3_2/` | v3.2 학습셋(`sft_train_v3_2_A.jsonl`, `sft_train_v3_2_B.jsonl`), 검증 파일, 분포 · 검사 보고서. 자세한 설명은 `v3_2/README.md` |
| `v3_2/prompts/` | v3.2 문장 생성에 쓴 지시문 원문. `b01~10` 유형 변환, `d01~04` 말투 다양화, `e01~02` 추가분 |
| `raw_elderly_public/` | 실제 노인 발화 313턴의 영상 URL + 시작 시각 + 라벨. 발화 원문은 싣지 않음 |
| `fill_minority/` | 실제 발화에 부족한 칸(생년월일 INFORM, 이름 UNCERTAIN)을 채우려고 직접 쓴 35문장 |

## 파일 이름 읽는 법

- `sft_train_*.jsonl`: 학습용(system · user · assistant 메시지 형식)
- `sft_valid_*.jsonl`: 검증용
- `v3_2/` 안의 `pattern` 값 `V32-P-T8-U`: 슬롯(P 전화번호, B 생년월일, N 이름, O 발생일, C 민원유형, R 회신방법, S 동의) - 하드 테스트셋 유형 번호 - 정답 라벨(I INFORM, U UNCERTAIN)
